## 0. Rules for the coding agent (also copy to repo-root `AGENTS.md`)

1. Treat `docs/` as the spec. If reality contradicts it, fix reality or log a dated deviation; do not silently diverge.
2. Anything tagged [U] must be verified (docs, upstream repo, or a test) before relying on it; update the tag to [V] with a URL and date.
3. Never write a metric you did not measure. Use `TBD`. No placeholder numbers in README, tables, or posts.
4. No dependency on the owner's other projects. **Amended 2026-10-27 (D11):** the measured
   stack runs a borrowed checkpoint (`lerobot/diffusion_pusht`), so using that project's policy
   code is now the point rather than a shortcut. What remains ours: the rollout harness, the
   control loop, the latency protocol, the normalization glue and the table/figure generators.
   Dataset converters and third-party weights must be labelled with their licence and pinned
   version (see [02](02_environment_setup.md) section 3.4).
5. Everything resumable; every result is a raw JSONL line; every figure/table is generated by a script from those files.
6. Small and finished beats large and half-done. Respect fallbacks and kill criteria in [06](06_decisions_and_risks.md).
