# Agent rules (mirror of docs/07_roadmap.md section 0)

Full operating rules: `CLAUDE.md`. This file exists so agents that only read `AGENTS.md`
still get the non-negotiables.

1. Treat `docs/` as the spec. If reality contradicts it, fix reality or log a dated
   deviation in `docs/CHANGELOG.md`; never diverge silently.
2. Anything tagged `[U]` must be verified (docs, upstream repo, or a test) before it is
   relied on; then change the tag to `[V]` with a URL and date.
3. Never write a metric you did not measure. Use `TBD`. No placeholder numbers in the
   README, tables or posts.
4. Do not depend on the owner's other projects. LeRobot/HuggingFace policy code may be
   read or used as a dataset converter (labelled), never as model code.
5. Everything resumable; every result is a raw JSONL line in `results/`; every figure and
   table is generated by a script from those files.
6. Small and finished beats large and half-done. Respect the fallbacks and kill criteria
   in `docs/06_decisions_and_risks.md`.

## Workflow

`/plan <step-id>` -> read the plan -> reply `GO <step-id>` and enable the green flag ->
the agent executes exactly that step and stops. One step at a time. The hook
`.claude/hooks/gate.py` blocks edits without `.claude/GREENLIGHT`.
